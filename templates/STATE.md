# STATE

Running log for a port. Append one section per session. Keep it short and factual:
what changed, what was verified, what is open.

## Session log

### SESSION 1 - YYYY-MM-DD

- Build: command and result (for example `DONE_EXIT_0`, errors=0).
- Changed: files and why.
- Verified: what was tested and the numbers.
- Open: anything unfinished, with the next step.
